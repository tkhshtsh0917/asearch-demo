# デモのドキュメント

[English](../README.md)

過去の計画・判断記録を読む前に、ルートREADMEと現行ランタイム契約を読んでください。識別子・コマンド・データ形式は両言語で共通です。英語ファイルを原文とし、日本語ファイルはその翻訳として同じ変更で更新します。

| 文書                             | 説明する内容                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| [データ](data.md)                | AutoWikiQAの出典、固定したrevision、質問の選択、帰属表示、ライセンス。                     |
| [配信](deployment.md)            | ReleaseからPagesへの自動配信、GitHub App設定、手動の版指定と切り戻し。                     |
| [性能](performance.md)           | Worker往復・DOM・起動の計測とその限界。                                                    |
| [検索用解析](search-analysis.md) | ネイティブの読み・ローマ字・同義語・クエリ変換、原文との分離、リソースの更新・固定、上限。 |

現行ランタイム契約は過去の設計記録より優先します。[integrationの仕様](../../integration/docs/ja/spec/README.md)がライブラリ境界を説明します。

[セキュリティ](security.md)は、ランタイムの管理責務、依存監査、非公開の報告方法を説明します。
